# 교과 개념 학습 프로그램 프롬프트

교과서 내용을 단순 암기하는 데서 끝나지 않고, 질문·탐구·개념의 일반화·새로운 상황에의 적용까지 이어지는 학습 프로그램을 만들기 위한 프롬프트입니다. 개념 기반 탐구, 질문 중심 수업, 평가·피드백, 게이미피케이션 원리를 반영했습니다.

## 사용 방법

아래 프롬프트를 AI 코딩 도구에 붙여 넣고, 대괄호 안의 교과·학년·단원 정보를 채워 사용하세요. 교과서 자료가 있다면 해당 도구에 별도로 제공하세요. 첨부된 교육 자료는 설계 참고자료이며, 교과 지식은 교과서와 교사가 제공한 자료를 기준으로 합니다.

## 프롬프트

```text
당신은 교육과정 설계자이자 학습용 웹 프로그램 개발자입니다. 교과서의 개념을 학생이 스스로 탐구하고 이해하도록 돕는, 실제로 실행 가능한 프로그램을 만들어 주세요. 계획서나 목업만 제시하지 말고 작동하는 최소 기능 제품(MVP)을 구현하세요.

## 만들 프로그램
- 프로그램명: [입력하거나 적절한 이름 제안]
- 교과·학년: [예: 초등 5학년 과학]
- 단원·주제: [입력]
- 학습할 교과서 내용: [텍스트를 붙여넣거나 파일로 제공]
- 주요 학습자 특성: [선택 입력]
- 사용할 환경: 웹 앱 기본, PC·태블릿·휴대전화에서 반응형으로 작동

## 참고할 교육 원리
첨부된 「개념기반탐구학습의실천」, 「질문과평가로깊어지는수업」, 「게이미피케이션개론」 자료를 교육 설계 참고자료로 활용하세요. 이 자료들은 수업 설계 원리의 참고자료이며, 교과 지식의 출처는 교과서와 교사가 제공한 자료입니다.

1. 단순한 사실 암기보다 사실·개념·개념 간 관계·일반화를 연결해 깊이 이해하게 합니다.
2. 학습 흐름은 다음 7단계를 중심으로 구성합니다. 단계는 반드시 직선으로만 진행하지 말고, 필요하면 이전 단계로 돌아가도록 합니다.
   - 관계 맺기: 흥미로운 사례나 상황으로 호기심을 일으킵니다.
   - 집중하기: 이번 탐구의 핵심 개념과 초점을 분명히 합니다.
   - 조사하기: 예시, 자료, 관찰 또는 문제를 살펴봅니다.
   - 조직 및 정리하기: 정보와 근거를 비교하고 관계를 정리합니다.
   - 일반화하기: 학생이 근거를 들어 핵심 원리나 개념 간 관계를 자기 말로 설명합니다.
   - 전이하기: 배운 개념을 처음 보는 사례나 실제 상황에 적용합니다.
   - 성찰하기: 무엇을 이해했고 어떤 질문이 남았는지 돌아봅니다.
3. 교사가 제시하는 안내 질문과 학생이 직접 만드는 질문을 모두 지원합니다. 질문은 사실 확인, 개념 이해, 토론·논쟁 질문 등 다양한 수준으로 구성하고, 단순 회상부터 근거를 활용한 추론과 전이까지 사고 깊이를 점진적으로 높입니다.
4. 정답을 바로 보여 주는 대신 학생의 생각을 먼저 끌어냅니다. 막히면 작은 힌트부터 단계적으로 제공하고, 학생이 답을 말한 뒤에는 근거나 사고 과정을 설명하게 합니다. 오개념은 비난하지 말고 확인 질문과 반례로 점검하게 합니다.
5. 퀴즈와 활동은 점수 산출에 그치지 않게 합니다. 답변을 바탕으로 현재 이해와 학습 목표 사이의 간극을 파악하고, 구체적이고 따뜻한 피드백과 다음 학습 제안을 제공합니다. 배운 내용을 기억에서 꺼내 보는 인출 활동도 포함합니다.
6. 게이미피케이션은 포인트·배지·순위표만 붙이는 방식으로 설계하지 않습니다. 의미 있는 선택, 적절한 도전, 진척의 가시화, 즉각적인 피드백, 성취감과 탐구의 재미가 학습을 돕도록 사용합니다. 연속 출석 실패에 대한 벌점이나 학생 간 공개 순위처럼 불필요한 압박은 피합니다.

## 핵심 사용 흐름
1. 학생이 단원에 들어와 짧은 사전 질문이나 문제를 풀며 현재 생각을 확인합니다.
2. 흥미로운 사례를 만나고, 오늘 탐구할 질문과 핵심 개념을 확인합니다.
3. 교과서에 근거한 예시·비예시·자료를 살펴보고, 학생이 직접 질문을 만들거나 고릅니다.
4. 학생이 근거를 기록하고 개념 간 관계를 정리합니다. 표, 간단한 개념도, 문장 틀 등 알맞은 표현 도구를 제공합니다.
5. 학생이 핵심 일반화를 자기 말로 작성하고, 프로그램은 근거가 충분한지 되묻습니다.
6. 새로운 상황에 개념을 적용하는 문제나 수행 과제를 해결합니다.
7. 마지막에 짧은 인출 퀴즈와 성찰을 진행하고, 다음에 공부할 내용을 제안합니다.

## 필수 기능
- 교사가 교과·학년·단원과 교과서 발췌 내용을 입력할 수 있는 설정 화면
- 학생이 쉽게 따라갈 수 있는 단계별 학습 화면과 현재 진행 표시
- 학생의 생각·질문·근거를 적고 다시 볼 수 있는 학습 기록
- 난이도가 다른 질문·문제와 단계별 힌트
- 이해 여부에 따라 보충 설명 또는 심화·전이 활동을 제안하는 기능
- 교사가 질문, 정답 기준, 간단한 평가 기준을 수정할 수 있는 기능
- 학습 완료 후 학생이 자신의 이해와 남은 질문을 확인하는 성찰 화면

## 정확성·안전·저작권
- 제공된 교과서 자료에 없는 사실이나 정답을 지어내지 마세요. 근거가 부족하면 “자료에서 확인할 수 없음”이라고 표시하고 교사에게 확인을 요청하세요.
- 생성한 설명과 문제는 교과서 문장을 길게 복사하지 말고, 개념을 바탕으로 새롭게 작성하세요. 자료를 참고한 경우 단원이나 쪽수를 표시할 수 있게 합니다.
- 학습자의 이름 등 불필요한 개인정보를 수집하지 마세요. 학생 답변은 학습 지원 목적으로만 사용하고, 부족한 답을 낙인이나 벌점으로 연결하지 마세요.
- AI가 학습자의 사고를 대신하지 않도록 하고, 학생이 먼저 생각하고 질문한 뒤 AI의 도움을 받는 흐름을 우선합니다.

## 개발 지침
- 먼저 현재 작업 공간의 파일과 기술 구성을 확인하고 기존 구조와 코딩 관례를 따르세요. 기존 프로젝트가 있다면 관련 없는 파일을 덮어쓰지 마세요.
- 별도 기술 구성이 없다면 간단하고 유지보수하기 쉬운 웹 앱으로 구현하고, 서버나 로그인 없이 기본 학습이 가능하도록 하세요.
- 모든 화면과 안내는 자연스러운 한국어로 작성하고, 글자 크기·색 대비·키보드 조작 등 기본 접근성을 고려하세요.
- 필요한 핵심 기능을 구현한 뒤 가능한 범위에서 실행 또는 테스트해 동작을 확인하세요. 오류나 미구현 기능은 숨기지 말고 보고하세요.

## 완료 기준
- 학생이 단원 선택부터 학습·피드백·성찰까지 실제로 완료할 수 있습니다.
- 학습 내용이 교과서에 근거하며, 정답 공개보다 질문·근거·개념 이해·전이를 중심으로 작동합니다.
- 교사 입력 내용이 학습 화면에 반영되고, 문제·힌트·피드백이 서로 일관됩니다.
- 실행 방법, 구현한 기능, 확인한 테스트, 남은 한계를 간단히 정리해 주세요.

정보가 충분하지 않으면 구현을 멈추고 질문만 나열하지 마세요. 먼저 꼭 필요한 사항만 질문하고, 답을 기다릴 수 없는 경우에는 가정을 명시한 뒤 기본값으로 작동하는 예시 단원을 만들어 구현하세요.
```

## 웹 인트로

정적 웹 인트로는 `index.html`, `styles.css`, `script.js`로 구성되어 있습니다. 저장소 루트에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`으로 확인할 수 있습니다.

참고 영상([약 15초](https://media.prompt-motion.com/stephanlivera-opus-5-5-on-max/video.86605038.mp4))은 0.5초 간격의 샘플 프레임으로 흐름을 확인했습니다.

| 구간 | 화면 흐름 |
| --- | --- |
| 0–2초 | 어두운 도트 바탕의 작은 코랄 점이 동심원과 방사형 심벌로 커집니다. |
| 2–4초 | 코랄 화면으로 전환되고 굵은 검정 타이포그래피가 크게 들어옵니다. |
| 4–6초 | 크림색 편집 화면에서 선과 점이 이동하며 여러 경로를 비교합니다. |
| 6–8초 | 블루 바탕 위 흰 기하 도형이 회전·변형하며 리듬을 바꿉니다. |
| 8–11초 | 검정·크림·코랄 패턴과 점 격자, 와이어프레임 형상이 이어집니다. |
| 11–15초 | 밝은 타이포 전환 뒤 코랄 배경과 심벌·타이틀로 정리됩니다. |

인트로에는 이 영상의 고대비 색상 전환, 절제된 기술 표기, 크게 읽히는 타이포그래피와 추상 도형의 움직임만 새롭게 적용했습니다. 영상의 로고·문구·장면은 그대로 복제하지 않았습니다.
